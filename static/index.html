Spirit Vale capture UI

Connected to the local capture app. WebSocket listens in the background while the timeline stays paused (nothing is written into the map/meter until you choose an action).

  1. Load a saved replay from disk or a previous session on the capture server.
  2. Listen (memory only) — buffer live packets in a ring buffer without following the cursor yet.
  3. Export / save buffer — download the in-memory window as .sv.replay.jsonl (server-side recording is still controlled by the Zig app flags).

Tip: for a full Echoing Spire run, prefer server file recording (-d ./replays). The browser keeps a capped recent window so RAM stays bounded.
